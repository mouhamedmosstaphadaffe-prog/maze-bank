# MAZE BANK
Un projet d'apprentissage.
Petite banque en console écrite en Python, 
avec création de compte avec hachage,
dépôts,
transferts,
boutique et historique.

### Installation

1. Installer Python dans [Python 3](https://www.python.org/downloads/) (cocher « Add Python to PATH » pendant l'installation)
2. Ouvrir un terminal dans le dossier du projet et installer les bibliothèques :
```
python -m pip install rich typer
```
### Lancement

```
python main.py
```
